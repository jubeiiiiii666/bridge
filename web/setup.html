Pocket Bridge

Installation sur ce téléphone (une seule fois)

1Télécharger le certificat

Il permet à Chrome de faire confiance à ton PC (connexion chiffrée, installation de l’app, notifications). Il ne concerne que ce PC.

Télécharger le certificat

2L’installer dans Android

  1. Ouvre Paramètres
  2. Sécurité et confidentialité → Autres paramètres de sécurité
  3. Installer depuis le stockage → Certificat CA → Installer quand même
  4. Choisis pocket-bridge-ca.crt dans Téléchargements

Astuce : tape « certificat CA » dans la recherche des Paramètres.

3Ouvrir l’app

  1. Ferme puis rouvre Chrome
  2. Dans VS Code, scanne le QR code « Appairer » : l’app s’ouvre déjà connectée
  3. Menu ⋮ → Ajouter à l’écran d’accueil → Installer
Tester la connexion sécurisée
